# Niraj SB — Portfolio

Personal portfolio website for Niraj SB, B.Tech IT student at Rajalakshmi Engineering College.

**Live Site:** https://zephyrgrimm.github.io/Portfolio/

## Tech Stack
- Next.js 15 (Static Export)
- TypeScript
- Tailwind CSS
- Deployed via GitHub Pages

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output is in `./out/`.
